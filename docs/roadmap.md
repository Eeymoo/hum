# 路线图

## 已完成的里程碑

### MVP1：基础记录 CRUD + CLI ✅

- [x] 通用健康记录的增删改查（类型 + JSON 数据 + 标签）
- [x] CLI 工具基础框架（Commander.js）
- [x] API Key 认证
- [x] 时间线查询
- [x] 端到端测试

### MVP2：专用命令 + 统计展示 ✅

- [x] 体重专用命令（`hum weight`）及统计（均值/极值/变化量）
- [x] 运动专用命令（`hum exercise`）及统计（频率/总时长/热量）
- [x] 饮食专用命令（`hum diet`）及统计（宏量营养素/日均热量）
- [x] 睡眠专用命令（`hum sleep`）及统计（平均时长/质量/深睡）
- [x] Web Dashboard 统计卡片

### MVP3：认证系统 + Web 可视化 ✅

- [x] 用户认证系统（NextAuth.js v5）
- [x] GitHub / Google OAuth 登录
- [x] 邮箱密码注册与登录
- [x] Web Dashboard 可视化图表（ECharts）
  - [x] 体重趋势折线图
  - [x] 运动频率柱状图
  - [x] 饮食营养素饼图
  - [x] 睡眠时长与质量对比图
- [x] 国际化支持（中文 / English）
- [x] Device Flow 认证（CLI 交互式登录）
- [x] API 密钥 Web 管理界面
- [x] Docker 部署与 CI/CD

### MVP4：数据导出 + 移动端适配 ✅

- [x] 前端 JSON 数据导出（设置页一键导出所有健康数据）
- [x] 移动端汉堡菜单导航
- [x] 响应式布局基础适配
