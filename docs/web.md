# Web 面板说明

Hum 提供基于 Web 的可视化管理面板，访问 `http://localhost:3000` 即可使用。

## 认证

支持三种登录方式：

- **GitHub OAuth**：点击 GitHub 按钮一键登录
- **Google OAuth**：点击 Google 按钮一键登录
- **邮箱密码**：在注册页创建账号后使用邮箱和密码登录

未登录用户自动重定向到 `/login`。

## 功能页面

### 概览 `/dashboard`

展示今日健康数据摘要：

- **最新体重**：显示最近一条体重记录及体脂率
- **最近睡眠**：显示最近睡眠时长及质量评分
- **今日运动**：今日运动次数及总时长
- **今日热量**：今日饮食总热量及餐数

底部提供四个快捷操作入口：记录体重、记录运动、记录饮食、记录睡眠。

### 体重 `/dashboard/weight`

- **统计卡片**：平均体重、最低体重、最高体重、30 天变化量
- **趋势图表**：ECharts 折线图展示 30 天体重变化趋势
- **记录列表**：最近 10 条体重记录
- **添加表单**：支持记录体重、体脂率、备注

### 运动 `/dashboard/exercise`

- **统计卡片**：总次数、总时长、总热量消耗
- **频率图表**：ECharts 柱状图展示各运动类型频率分布
- **记录列表**：最近 10 条运动记录
- **添加表单**：支持选择类型、时长、热量、感受等

**支持的运动类型**：跑步、力量训练、骑行、游泳、其他

### 饮食 `/dashboard/diet`

- **统计卡片**：日均热量、平均蛋白质/碳水/脂肪
- **营养素图表**：ECharts 饼图展示三大营养素分布
- **记录列表**：最近 10 条饮食记录（带餐别图标）
- **添加表单**：支持选择餐别、热量、宏量营养素、食物列表

**支持的餐别**：早餐、午餐、晚餐、加餐

### 睡眠 `/dashboard/sleep`

- **统计卡片**：平均时长、平均质量、平均深睡时长
- **对比图表**：ECharts 柱状图展示近 7 天睡眠时长与质量
- **记录列表**：最近 10 条睡眠记录
- **添加表单**：支持时长、入睡/醒来时间、质量、深睡/REM 时长

### 时间线 `/dashboard/timeline`

聚合展示所有健康数据的统一时间线，按时间倒序排列：

- 体重记录
- 运动记录
- 饮食记录
- 睡眠记录
- 通用记录

### 记录 `/dashboard/records`

通用健康记录管理：

- **记录列表**：显示类型标签、标签、备注、JSON 数据
- **添加表单**：支持选择类型、输入 JSON 数据、添加标签和备注
- **删除功能**：每条记录可单独删除

**记录类型**：笔记、心情、症状、药物、测量、其他

### API 密钥 `/dashboard/api-keys`

- 创建新的 API 密钥（名称自定义）
- 查看已创建的密钥列表（仅显示名称和创建时间，不显示密钥内容）
- 删除不再使用的密钥

**注意**：密钥仅在创建时显示一次，请立即复制保存。

### 设置 `/settings`

- **个人资料**：查看和修改账号信息
- **API 密钥**：快捷入口到密钥管理页
- **数据导出**：导出所有健康数据（JSON/CSV，功能预留）
- **账号管理**：退出登录

## 国际化

Web 面板支持中文和英文，根据浏览器语言自动切换。国际化文件位于 `apps/api/messages/` 目录。

## 响应式设计

- 桌面端：顶部导航栏 + 主内容区
- 移动端：汉堡菜单导航 + 卡片式布局
